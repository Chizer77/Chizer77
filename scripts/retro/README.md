# 像素动画


在项目根目录运行：

```powershell
python -m pip install -r scripts/retro/requirements.txt
python -B scripts/retro/crow/generate.py
python -B scripts/retro/phorni/generate.py
```

| 内容 | 路径 |
| --- | --- |
| 乌鸦成品 | `assets/crow/crow.svg`、`crow.gif` |
| 芙铃成品 | `assets/phorni/phorni.gif`、`phorni.svg`（均为完整动作循环） |
| 乌鸦离线预览 | `scripts/retro/previews/crow/index.html` |
| 芙铃离线预览 | `scripts/retro/previews/phorni/index.html` |
| 乌鸦生成代码和源姿势 | `scripts/retro/crow/` |
| 芙铃生成代码和源姿势 | `scripts/retro/phorni/` |
